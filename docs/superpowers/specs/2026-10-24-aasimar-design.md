# Legacy 5e Aasimar and variants

The user supplied two Aasimar rules pages and requested the race and variants in 5e character creation. Implement the supplied legacy rules (Volo’s Guide to Monsters, pp.104–105) under the 2014/5e ruleset, also available to Custom with 2014 mechanics. Do not substitute the revised Aasimar rules or add this source to the 2024/3.5 creation lists.

One source-labelled Aasimar option requires Protector, Scourge or Fallen in the existing subrace selector. Base Charisma +2; variant Wisdom/Constitution/Strength +1 respectively. Medium, speed 30, darkvision 60 feet, Common and Celestial, radiant/necrotic resistance, Healing Hands (action, heal character level once per long rest), and Light at will using Charisma. Preserve background language choices. Save all shared/variant traits and show the selected variant’s traits during creation. Optional angelic-guide lore is descriptive, not a mandatory setup requirement.

At character level 3 grant the selected transformation, once per long rest, action to activate, 1-minute duration, bonus action to end. Protector: 30-foot flight and once on each own turn +level radiant damage to a damaged attack/spell target. Scourge: 10-foot bright/another 10-foot dim light; end-of-own-turn aura affects self and all creatures within 10 feet for ceil(level/2) radiant damage, plus the same +level radiant damage once on each own turn. Self aura damage is halved by Celestial Resistance (round down). Fallen: visible others within 10 feet who can see the character make Charisma saves (8 + proficiency + Charisma modifier) or are frightened until the end of the character’s next turn; once on each own turn +level necrotic damage to a damaged attack/spell target. Fallen wings grant no flight.

Approach: extend the existing canonical race/subrace creation flow and reuse race-managed resource counters, following Eladrin’s integration. This is less invasive than three unrelated race cards or a new creation flow. Add an Aasimar action/trait panel for Healing Hands (self applies capped HP; another creature is resolved at the table), transformation spending/ending and exact rules. Add a racial Light row in Spells, independent of class cantrip counts/slots/ability. Reconcile source-owned traits without duplicates or deleting unrelated homebrew traits; match exact source identity so other Aasimar records are unaffected. Rest recovery uses existing shared counters; any completed rest ends the minute-long form. Activation is blocked at 0 HP/incapacitation or without uses. No automatic encounter clock, external-target damage/healing or automatic extra attack damage: explicit rules and values guide table resolution.

No dependencies, catalog overwrites or database migrations. Deliver a tested reviewable PR; merging remains a separate user action.
